# ai-tools-labAI Tools Lab

Project Description

AI Tools Lab is a Python project created for learning and experimenting with AI-assisted programming and basic Python utilities. The project contains sorting algorithms and useful utility functions such as palindrome checking, word counting, and temperature conversion.

Installation

1. Make sure Python 3 is installed on your computer.
2. Clone the repository:

git clone https://github.com/Mehakpreet/AI-Tools-Lab.git

3. Open the project folder:

cd AI-Tools-Lab

No external Python packages are required for the basic programs in this project.

Usage

Sorting Example

The project contains Python programs demonstrating sorting algorithms.

numbers = [5, 2, 8, 1, 3]
numbers.sort()
print(numbers)

Output:

[1, 2, 3, 5, 8]

Utility Functions

The utility module provides functions such as:

from utils import is_palindrome, count_words, celsius_to_fahrenheit

print(is_palindrome("madam"))
print(count_words("Hello Python World"))
print(celsius_to_fahrenheit(25))

Output:

True
3
77.0
