# Task 3 — Improve Code Quality with AI Review

## Original Code
The original code was working but messy. It had poor variable names,
no docstring, no error handling, and poor formatting.

## Improvements Suggested by AI

1. **Readability:** The code was formatted with proper spacing and indentation.
2. **Variable naming:** `calc`, `a`, `b`, and `x` were replaced with meaningful names.
3. **Error handling:** `try-except` was added to handle possible errors.
4. **Docstring:** A docstring was added to explain what the function does.
5. **PEP 8:** The code was formatted according to Python's PEP 8 style guidelines.

## Result
The improved program was tested in VS Code and produced:

20.0
## Discussion: Can AI Replace Code Review?

AI can help with code review by finding common errors, improving
readability, suggesting better variable names, and checking coding
style. However, AI cannot completely replace a human code reviewer.

AI may miss important business requirements, project-specific rules,
security problems, or situations where the code works but does not
solve the actual problem correctly. AI suggestions can also sometimes
be incorrect.

Therefore, AI is a useful assistant for code review, but human review
is still important for making the final decision.
